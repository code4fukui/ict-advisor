# ict-advisor

このリポジトリには、総務省が地方自治体のICT導入を支援する事業である「地域情報化アドバイザー（ICTアドバイザー）派遣制度」のガイドラインが含まれています。

## プログラム概要

本プログラムは、ICTを活用した地域活性化を目的としています。主な活動内容は以下の通りです。
- 地方自治体に専門アドバイザーを派遣し、ICTの活用を支援します。
- 地域社会におけるICT導入をサポートするためのアドバイス、提言、情報を提供します。
- 地域の担当者をICTの中核リーダーに育成するための研修を行います。

## 申請手続き

本プログラムは、日本の地方自治体および関連団体を対象としています。

- 対象となる団体は、総務省に申請し、ICTアドバイザーの派遣を依頼できます。
- 総務省が申請を審査し、承認された場合は適切なアドバイザーを割り当てます。
- アドバイザーの派遣は原則として、最大3日間、1日あたり最大7時間までです。
