# ict-advisor

> 日本語のREADMEはこちらです: [README.ja.md](README.ja.md)

This repository contains the guidelines for the Regional Informatization Advisor (ICT Advisor) Dispatch Program, a project by the Japanese Ministry of Internal Affairs and Communications to support ICT adoption by local governments.

## Program Overview

The program aims to promote the use of ICT to revitalize local communities. Key activities include:
- Dispatching expert advisors to local governments to assist with ICT utilization.
- Providing advice, recommendations, and information to support the adoption of ICT in local communities.
- Training local personnel to become core ICT leaders.

## Application Process

This program is available to local governments and related organizations in Japan.

- Eligible organizations can apply to the Ministry of Internal Affairs and Communications to have an ICT advisor dispatched.
- The Ministry reviews the application and, if approved, assigns an appropriate advisor.
- Advisor dispatches are generally for a maximum of 3 days, up to 7 hours per day.
